## 色彩角色
`色值`一列必须填精确色值，且逐字取自 [brand-system.md](../references/brand-system.md) 的「正式色彩角色」表；本文件不复述色值，避免出现第二份品牌权威。只允许该表已确认的品牌 token；浅色或白色阅读表面是应用默认，不是品牌 token，不进入精确色值门。

| 角色 | 色值 | 功能解释（为什么用这个颜色） |

| 背景 / 阅读表面（应用默认，非品牌 token，不进入精确色值门） | | |
| 主导结构（`AB_BLUE_1`） | | |
| 支撑层次（`AB_BLUE_2`） | | |
| 次级数据层（`AB_BLUE_3`） | | |
| 信号 / 重点（`AB_BLUE_4`） | | |
| 正文 / 深色场（`AB_CHARCOAL`） | | |

行集合固定为「一个阅读表面 + 五个 token」：五个 token 都必须有槽位，不需要再加行，也不得自造第六个品牌色；某角色本稿未使用时写 `N/A` 并说明替代方式。

## 字体角色
字样与字重取自 [brand-system.md](../references/brand-system.md)；不得自造字样或字重，也不得声明该文件标为待确认的字样命名。回退链是渠道实现细节，取值见 [channel-wechat.md](../references/channel-wechat.md)。精确生产文件与授权待确认。上游 VI 不随附字体文件：渲染前必须用 `fc-match '<family>'` 或输出文件的 `/BaseFont` 表确认实际解析到的 family，并把实际 family/字重/文件与授权填入「实际文件/来源」列；解析到替代字体时交付状态记 `待确认`，不得声明已按 VI 字体渲染。
