# 视觉决策追踪表

| 字段 | 内容 |
|---|---|
| 决策 ID | `DT-001` |
| 内容目标 | 受众、理解目标、预期行动 |
| 视觉命题 | 内容如何转为空间、构图或图像关系 |
| 具体决策 | 网格、字体、颜色、图像类型、母题或动效 |
| 规则来源 | VI / 用户内容 / 研究来源 / 项目默认值 / embedding 召回 |
| 来源定位 | 文件、章节、页码或 URL；未知标 `TBC` |
| 适用范围 | 渠道、尺寸、受众、阅读距离、媒介 |
| 预期收益 | 清晰度、识别、层级、可信度、行动 |
| 风险与反例 | 误读、品牌漂移、对比度、版权或生产风险 |
| 验证方法 | 黑白、缩略图、实际尺寸、对比度、用户测试、打样 |
| 结果 | 通过 / 修改 / 暂停 / 待确认 |
| 决策人和日期 | 负责人、版本和日期 |

## 使用规则

1. 用户原始要求和正式 VI 优先于研究启发式与 embedding 召回。
2. embedding 只能提供候选，不得自动批准设计或推断事实。
3. 研究来源提供方法，不自动成为品牌硬规范。
4. 结构方向先记录主导关系、网格和阅读路径，再进入完整制作。
5. 多个方向连续被否决时，返回内容契约或视觉命题，不继续堆叠装饰。
