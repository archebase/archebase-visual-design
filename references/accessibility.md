# 视觉无障碍与辅助技术交付

本文件将《Graphic Design for Course Creators》的教学内容与当前无障碍实践边界结合。具体合规结论必须注明适用的 WCAG 版本、目标等级和未覆盖范围。

## 语义优先

- 有信息意义的图片、图表、流程图和信息图提供等价替代文本或长描述；装饰图形标记为装饰。
- 图片中的关键文字优先保留为真实、可选择文本；图表替代文本说明结论、趋势和关系。
- 使用真实 H1–H6、文档标题样式和原生列表，不用字号、加粗、空格或手打符号伪造语义结构。
- 链接标签说明目标，如“下载 2026 数据基础设施报告”，避免“点击这里”。

## 视觉与动态检查

- 按当前适用 WCAG 版本检查正文、标题、链接、图标和 UI 状态的对比度。
- 关键意义不能只靠颜色；同时使用文字、形状、位置、图案、图标或线型。
- 检查灰度、色觉模拟、缩放、低亮度、手机尺寸和实际导出文件。
- 不把某种字体、字号或行距宣称为对所有人最易读；应在真实设备、字号和目标用户中测试。
- 视频提供同步字幕，音频/视频提供文字稿或等价替代；避免自动播放有声内容和危险闪烁，关键步骤提供静态摘要。

## ArcheBase 默认与交付

保留 Source Han Sans SC 与 Poppins 的品牌角色，但验证字符覆盖、嵌入、实际字重和小尺寸可读性。先用黑白原型确认层级，再加入品牌色。极简不等于删掉必要标签、来源、反馈或文本替代。

- [ ] 关键文字不是只存在于图片像素中。
- [ ] 标题、列表、链接和按钮使用真实语义结构。
