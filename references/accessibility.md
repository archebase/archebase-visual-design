# 视觉无障碍与辅助技术交付

本文件将《Graphic Design for Course Creators》的教学内容与当前无障碍实践边界结合。

## 标准声明

- 适用的 WCAG 版本与目标等级必须按项目声明并记录在交付文档中，不得假定或跨项目沿用；未声明时不得给出“符合/通过”结论。记录版本、等级、适用范围和未覆盖项。
- 对比度实测只使用本技术栈中的 `<ARCHEBASE_DESIGN_IR>/inspect_raster.py`（环境变量 `ARCHEBASE_DESIGN_IR` 解析 store 根；不可达时按待确认停止）：
  `python3 <ARCHEBASE_DESIGN_IR>/inspect_raster.py <image> --text-color '<hex>' --background-color '<hex>' [--large-text]`
  阈值：4.5:1（正文）、3.0:1（大字号，加 `--large-text`）。
- 该工具的局限性：**不定位文字区域**，只对显式给出的前景/背景色对计算比值；也不识别字体、不证明 Logo 完整性或合规。对比度结论必须配合文字区域人工取样或其他实测。

## 语义优先

- 有信息意义的图片、图表、流程图和信息图提供等价替代文本或长描述；装饰图形标记为装饰。
- 图片中的关键文字优先保留为真实、可选择文本；图表替代文本说明结论、趋势和关系。
- 使用真实 H1–H6、文档标题样式和原生列表，不用字号、加粗、空格或手打符号伪造语义结构。
- 链接标签说明目标，如“下载 2026 数据基础设施报告”，避免“点击这里”。

## 视觉与动态检查

- 按项目已声明的 WCAG 版本与等级检查正文、标题、链接、图标和 UI 状态的对比度；不得改用其他版本或等级。
- 关键意义不能只靠颜色；同时使用文字、形状、位置、图案、图标或线型。
- 检查灰度、色觉模拟、缩放、低亮度、手机尺寸和实际导出文件。
- 不把某种字体、字号或行距宣称为对所有人最易读；应在真实设备、字号和目标用户中测试。
- 视频提供同步字幕，音频/视频提供文字稿或等价替代；避免自动播放有声内容和危险闪烁，关键步骤提供静态摘要。

## ArcheBase 默认与交付

保留 Source Han Sans SC 与 Poppins 的品牌角色，但验证字符覆盖、嵌入、实际字重和小尺寸可读性。先用黑白原型确认层级，再加入品牌色。极简不等于删掉必要标签、来源、反馈或文本替代。

- [ ] 每个有意义的图像和图表都有替代文本或长描述。
- [ ] 关键文字不是只存在于图片像素中。
- [ ] 标题、列表、链接和按钮使用真实语义结构。
- [ ] 已声明并记录 WCAG 版本、目标等级与适用范围，并按该声明实测对比度。
- [ ] 关键信息不只依靠颜色。
- [ ] 已做灰度、色觉、缩放和实际尺寸检查。
- [ ] 媒体有字幕、文字稿或静态替代；无自动播放有声内容或危险闪烁。
