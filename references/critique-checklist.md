# 视觉审查清单

## 快速审查

- 三秒内能否识别主题？
- 是否只有一个主导视觉？
- 核心信息和 CTA 是否清楚？
- 是否使用精确品牌色和正确字体角色？
- 是否落入泛化 AI 俗套？

## Gate A：内容正确性

- [ ] 无编造产品能力、客户、指标、数据或“领先”措辞。
- [ ] 标题、数据、来源、日期、CTA 与材料一致。
- [ ] 图形不暗示未经确认的架构。
- [ ] 装饰图表不会被误认为真实数据。

## Gate B：信息与构图

- [ ] 只有一个明确主导视觉。
- [ ] 阅读路径连续。
- [ ] 相关内容成组，不相关内容有分隔。
- [ ] 对齐依据可解释。
- [ ] 留白承担聚焦、分隔或节奏功能。
- [ ] 对比足够果断。
- [ ] 规则破坏有明确沟通收益。

## Gate C：品牌一致性

- [ ] 色值精确：`#0032FF #7172FA #619AFD #46CFFF #1E2124 #FFFFFF`。
- [ ] 中文优先 Source Han Sans SC；英文优先 Poppins。
- [ ] 白底小字未使用低对比辅助色。
- [ ] 没有未经批准的橙色 CTA/状态色。
- [ ] 至少体现基础、秩序、坐标、数据连接或受控流动之一。
- [ ] Logo 未变形、改色或添加效果。

## Gate D：生产与可访问性

- [ ] 正文对比度按 WCAG AA 实测。
- [ ] 关键意义不只靠颜色。
- [ ] 在最终尺寸检查正文、图注和细线。
- [ ] 图像裁切未遮挡关键对象。
- [ ] 尺寸、格式、色彩模式、安全边距明确。
- [ ] 手机缩略图不依赖微小细节。
- [ ] 渠道不支持的布局能力已替换。
- [ ] 任何检索候选均已通过硬约束过滤，并记录来源、采用理由或淘汰原因。

## 修订优先级

1. 事实错误。
2. 可读性和对比度。
3. 信息层级。
4. 品牌违规。
5. 构图关系。
6. 风格精修。
