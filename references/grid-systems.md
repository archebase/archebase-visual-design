# 网格系统：建立、变化与破格

本文件转化 Timothy Samara 的网格方法，用于构图判断，不构成智域基石 VI 硬规范。

## 网格类型

| 类型 | 适用 | 智域基石应用 |
|---|---|---|
| 单栏/手稿 | 连续阅读、单一内容 | 报告、白皮书、观点长图；控制行长和边距 |
| 分栏 | 图文并置、多类短信息 | 技术文章、观点/证据、能力/说明 |
| 复合分栏 | 同页信息类型差异大 | 正文、参数、引用、图表共享主轴 |
| 模块网格 | 高复杂度、表格、卡片、系列 | 数据流程、能力矩阵、案例集合 |
| 层级网格 | 内容尺度变化大、不适合等分 | 海报、首页、主视觉、信息图 |
| 复合结构 | 长内容、多媒介系统 | 报告、活动系统、跨渠道物料 |

## 建立网格

1. 盘点标题、正文、图像、数据、图注、来源和 CTA，记录长短、比例、频率和优先级。
2. 同时确认尺寸、装订/折叠、手机裁切、响应、印刷、最长标题、缺图状态和协作需求。
3. 选择最低必要复杂度：连续正文用单栏，并列内容用分栏，高密度才用模块，不规则内容用层级网格。
4. 定义边距、栏、流线/挂线、模块、空间区和稳定标记位。
5. 用真实正文、最长标题、最大数据和真实图像决定尺度，不从“几栏”开始。
6. 固定主轴、边距、字体角色、颜色角色、模块比例、来源/CTA 位置；允许图像跨度、密度、裁切、留白和局部比例变化。
7. 用超长标题、最短页面、缺图、密集数据、横竖极端图测试后再冻结。

## 序列与系统化

- 网格提供清晰、效率和连续性，不要求每页相同。
- 长图、报告、轮播和系列海报先做缩略图故事板，比较每页信息量、明暗密度、主视觉位置、疏密和静动节奏。
- 固定品牌色、字体角色、主网格、核心轴线、基本单元和来源区；变化数据密度、图像跨度、节点、流向和局部尺度。
- 多人协作记录语义规则，例如“右窄栏只放来源”“信号青只用于流向”，不只交付辅助线。

## 非网格与解构

无网格不等于无组织，可用以下关系替代统一直角坐标：

- **局部解构**：总体网格保留，仅主标题、关键图像或数据越栏、出血、偏移或打断流线。
- **多层结构**：不同信息层使用各自栏或平面，以尺度、透明度、密度和前后关系建立深度。
- **拼贴组织**：依内容层级裁切和叠加，仍靠邻近、对比和空间明确关系。
- **概念解构**：形式直接解释主题，如分散、汇聚、断裂；概念必须来自内容。
- **图像导向**：围绕设备轮廓、空间透视、运动方向组织文字，但字体角色稳定。
- **时间/过程结构**：以帧、阶段和数据流组织，适合感知到行动的表达。
- **光学构图**：以视觉重量、张力、方向、尺度、密度和留白平衡，适合低信息主视觉，不适合高密度说明。
- **受控偶然**：预设元素、范围和操作，再人工校正层级与可读性。

## 破格门槛

仅当规律性削弱核心信息，或需要表达异常、转折、突破、流动、时间、层叠、非线性和系列节奏时破格。

执行：
1. 指明打破的是栏、流线、边距、模块、基线还是阅读顺序。
2. 保留至少一个锚点：主轴、标题、字体角色、颜色角色或固定区。
3. 只让主角或明确例外越界。
4. 通过尺度、位置、留白或密度制造张力，品牌色不能替代结构。
5. 隐去辅助线后，观众仍能判断主次、关联和行动。

## 失败模式

- 先画网格再塞内容。
- 网格过细，制造伪精密和噪声。
- 机械填满模块，所有区域等重。
- 把可见网格当科技纹理。
- 一页一种逻辑，系列断裂。
- 随机冒充自由，破格没有语义。
- 实验形式遮挡来源、数据、正文或 CTA。
- 直接移植历史案例外观为品牌风格。

## 验证

- 去掉辅助线后，对齐、分组和空间区是否仍可感知？
- 三秒能否识别主题，正文、数据、来源、CTA 是否易定位？
- 长标题、缺图、最大数据和最小屏幕是否通过？
- 缩略图故事板是否有规律节奏而非重复/随机？
- 能否说出被破坏的规则和收益？恢复规则后若表达不变弱，则取消破格。
