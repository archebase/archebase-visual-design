# 参考图保真与佩戴几何

本文件把「参考图 → 空间模型 → 几何不变式 → 提示词 → 评审」变成可执行、可证伪的流程，用于任何**真实器件出现在人身上或环境中**的写实图像任务：产品手册封面、佩戴照、现场摄影 brief、图像生成 brief。

它是本 Skill 自定的工作方法，不是 VI 原文条款。品牌事实、Logo 资产与色值仍以上游 VI 为准（见 [brand-system.md](brand-system.md)、[source-boundaries.md](source-boundaries.md)）；本文件只管**器件与人体、器件与环境的空间关系是否可信**。

## 何时使用

- 任务给出至少一张真实器件/现场参考图，并要求不重绘该器件。
- 器件被佩戴、握持、穿戴或与人体接触，几何错误一眼可辨。
- 需要多轮迭代，且上一轮「看起来更好」但器件关系仍然不对。

不适用：抽象图形、图示、数据图任务（见 [image-and-information-design.md](image-and-information-design.md)）；也不用于判断参考图本身的品牌合规性（那是 VI 层的事）。

## 1. 参考契约：一张图一个角色

每张参考图登记**恰好一个角色**，并同时写明两件事：哪些特征不可变，哪些内容不得复现。

| 角色 | 典型不可变特征 | 常见误复现 |
|---|---|---|
| 头部/面部器件 | 壳体轮廓、部件数量与相对位置、镜头布局、表面处理与颜色分块、Logo 面板、侧臂与头带走向 | 产品图白底、棚拍布光、假人或支撑物 |
| 左/右腕部器件 | 环体形状、模块连接点与延伸方向、镜头位置与朝向、绑带走向 | 器件自身的演示角度被当成佩戴角度 |
| 器件细节图 | 局部结构、按钮/接口数量与排列 | 把局部图误当成整体比例依据 |
| 人物/服装 | 年龄段、气质、服装色系与结构 | 参考模特的身份与可辨识特征 |

- 不可变（`immutable`）：外形轮廓、部件数量与相对位置、材料与表面处理、颜色分块、品牌面板、接口/绑带走向、相对比例。**不得重绘、简化、重新设计或替换。**
- 不得复现（`excluded`）：参考图自带的背景、假人/支撑物、棚拍布光、水印、字标、演示姿态、无关器材。
- 参考图角色冲突（一张图被要求承担两个角色）或角色缺失时先停：补图或由人明确取舍，**不得让生成模型自行决定哪张图说了算**。

## 2. 空间模型：用平面、轴、接触面说话

把每张图读成三维关系，而不是形容词。逐项回答，不确定的写 `待确认`：

1. 器件哪一面朝向观察者？该面的法线朝哪一侧？
2. 与人体接触的是什么形状（环、带、夹、壳、贴片）？它的平面与**哪条身体轴**垂直或平行？
3. 附属模块从哪个点开始、沿哪个方向延伸？它是否与主体共面？
4. 镜头/传感器的光轴落在哪个平面里、指向哪一侧？
5. 哪些部件会被身体、衣物或器件自身遮挡？
6. 画面里的比例基准是什么（腕宽、头宽、瞳距、壳体长宽比）？

方法：分角色看全图 → **裁切并放大**器件与身体的接触处、模块与主体的连接处 → 用上述六个问题写结论 → 只保留下一轮出图能复核的结论。

## 3. 几何不变式：可证伪、可裁切复核

每条不变式写成一句话：`<关系> + <复核位置> + <判据>`。例如：

- 环平面垂直于前臂轴（腕部局部裁切：环开口应朝向手背或掌心，而不是画面上方）。
- 附属模块接在环的最低点，沿环平面内的方向悬挂，不得从环平面里「拧出来」。
- 镜头光轴落在环平面内（径向朝外），不在环法线上——这样镜头对着的物体与环始终共面。
- 绑带绕腕一周，从外侧压住环体，接触处有压力痕迹。
- 壳体正面下缘高于眉弓，双眼与完整面部可见（不得退化成 VR 头显）。
- 多镜头布局中，大镜头与四角小镜头的相对位置、数量不得互换或增减。

禁止用「更真实」「更自然」「更高级」这类不可复核的表述充当不变式。每条不变式必须同时具备：

- `observation`：复核时看哪一块画面（可裁切的区域）。
- `prompt_clause`：提示词中对应的一句；**没有对应句 = 该不变式没有被表达**。
- `status`：`pending` / `pass` / `fail` / `待确认`。

格式与字段见 [../templates/spatial-fidelity-spec.json](../templates/spatial-fidelity-spec.json)，可用 `python3 evals/check_spatial_spec.py --spec <spec.json>` 校验。

## 4. 姿态优先（本文件的核心规则）

**投影几何由姿态决定，不由措辞决定。**

- 先定姿态再定不变式，或先列出不变式、再挑出能让它们同时成立的姿态；两者矛盾时改姿态。
- 反例（已实测）：前臂近竖直 → 环面近水平 → 挂在环下的模块只能横向支出 → 与「模块垂于环下」矛盾。此时加形容词、加约束句都无用，必须把前臂放到接近水平。
- 不得为了展示某个部件而旋转、抬起、放大或翻转器件朝向——那会同时破坏器件与人体的一致性，把佩戴照变成产品图。
- 姿态还必须与画幅职能相容：封面留白、视线方向、双腕与躯干分离是构图要求，姿态要一次同时满足它们。

## 5. 真实优先于展示

- 遮挡、背对镜头、失焦、被袖口或手掌压住，都是真实佩戴的正常结果：**允许并鼓励保留**。
- 只有当遮挡让器件完全不可辨认、从而影响图像主职能时，才调整姿态；调整对象是姿态，**不是器件朝向**。
- 遮挡策略必须显式写进 brief 与规格，例如：「镜头可被手掌、手腕或袖口遮挡或背对镜头；不得为露出镜头而改变姿态」。

## 6. 单变量迭代与评审记录

- 每轮只改一个变量：姿态 / 器件保真 / 背景纯净度 / 光比 / 裁切。多变量同改则无法归因。
- 候选编号连续（A、B、C…），记录：改动变量、失败的不变式编号、淘汰理由。评审以「哪条不变式失败」为单位，不用「更好/更差」。
- 同一条不变式连续两轮失败 → 停止调整措辞，回到空间模型重读参考图。
- 迭代记录写进规格的 `candidate_log`；最终交付必须给出「通过的不变式 + 已知无法消除的偏差（`known_limits`）」，不得声称完美复刻。

## 7. 反模式

- 为了露出镜头/传感器而旋转器件、翻转手腕或改变手部朝向。
- 把附属模块画出环平面（看起来被拧出来）。
- 把参考图的背景、假人、棚拍光一并复现。
- 器件漂浮：无接触面、绑带不承力、无压力与遮挡。
- 用「更真实」或更长的提示词掩盖几何矛盾。
- 把用户对几何的纠正当成措辞问题，只往提示词里加形容词。
- 额前设备下压遮住眼睛，退化成 VR 头显。
- 把生成像素重建的品牌字标直接当印刷终稿：印刷交付必须回到官方资产做确定性叠加。

## 8. 质量门挂钩

参考图保真与空间自洽按 **Gate G** 单独执行（见 [critique-checklist.md](critique-checklist.md)），并与 [SKILL.md](../SKILL.md) 质量门 7 一一对应；任一不变式为 `fail` 时不得交付。

## 9. 案例：本方法的来源

ArcheBase 可穿戴数据采集系统产品手册封面：1 张头戴设备参考 + 2 张腕部器件参考（正面/背面），共 10 稿（A–J）。

- 失败模式：E/F/G 三稿都做到了「环在上、模块在环下」，但前臂近竖直使环面近水平，模块只能横向支出，与参考图矛盾；提示词越写越细，矛盾不变。
- 翻盘条件：把姿态改为**前臂接近水平**（双手放松置于髋前），环面转为竖直，模块自然垂挂且与环共面，镜头允许被手掌遮挡 → 通过。
- 附带结论：生成像素重建的品牌字标只能作占位；印刷交付应按 VI 用官方 Logo 资产确定性叠加。
