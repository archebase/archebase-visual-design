# 微信公众号渠道

本文件是渠道实现规则，不是所有媒介的全局品牌定律。

## 文章视觉

- 白底正文，正文色 `#1E2124`。
- H1：主蓝左脊柱、青色下边线、浅蓝背景面。
- H2：主蓝左线、浅蓝下边线。
- H3：青色左线、弱主蓝下边线。
- 表头可用 `#0032FF` 配 `#FFFFFF`。
- 深色总结模块用 `#1E2124` 为底，`#46CFFF` 仅作重点与边线。
- 图片宽度自适应，关键文字不要烘焙进低分辨率图片。

## 字体回退

`Source Han Sans SC` → `Noto Sans CJK SC` → `PingFang SC` → `Microsoft YaHei` → 系统 sans-serif。

## 兼容限制

默认不依赖：

- `flex`
- `grid`
- `object-fit`
- `:has`
- `clamp`

复杂双栏和浮动结构需在微信手机端实测；必要时改为块级单栏。细线、浅蓝与青色在不同屏幕上可能变弱，应检查截图和实际预览。

## 选择器冲突处理

现有 CSS 局部存在不同强调行为。以上位规则为准：白底正文强调用 `#0032FF`；青色不用于白底小正文。渠道浅色背景（如淡蓝白）是安全映射，不自动成为新的核心品牌色。

## 微信交付检查

- iOS 与 Android 预览。
- 小屏行长、标题换行、表格横向溢出。
- 深底模块反白文字对比。
- 图片压缩后的细线和小标签。
- 复制粘贴后样式是否被编辑器剥离。
