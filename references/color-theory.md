# 色彩理论与媒介适配

色彩理论用于解释和组织 ArcheBase 固定色板，不自行改变品牌事实。颜色事实、已批准 token、比例和语义角色以 `archebase-vi-guide` 为准。

## 固定角色

品牌色板与角色只在 [brand-system.md](brand-system.md) 声明，本文件不重复色值。品牌色板是上游定义的五个 token，其中没有白色 token（上游 `tokens/archebase.tokens.json`；`references/visual-grammar.md:5-8`）。白/浅色阅读表面是应用默认，不是品牌 token。

先用明度建立结构，再用主蓝建立识别，最后用辅助蓝和信号青建立有限层次。白底小正文不默认使用浅蓝、辅助蓝或青色。

## 模式边界

- `strict`：色相限定在 VI Guide 已批准体系内，只使用已批准品牌 token。
- `guided`：默认使用品牌 token；非 token 颜色只能作为明确标注的渠道/活动扩展色。
- `creative`：可为渠道或活动增加扩展色，但必须标明其不是官方品牌 token，记录用途与偏离理由，并通过 `archebase-vi-guide` 对应模式的发布门禁。
- `off`：不执行 ArcheBase 品牌色规则，也不得声称 VI 合规。

## 感知、面积与媒介

颜色外观取决于背景、邻色、形状、面积、位置和媒介。分别在白底、深底、图像底和真实尺寸中检查。大面积颜色成为环境，小面积颜色更容易成为焦点；信号青扩大后不得夺走主蓝的品牌主导。

色彩变化优先按明度、彩度、透明度、面积和位置处理。屏幕是 RGB 加色环境，印刷是 CMYK/专色减色环境。印刷交付必须记录色彩配置文件、纸张/工艺和打样状态；未经正式规范或供应商确认，不把脚本换算结果当作品牌标准。

## 色彩和谐：用关系建立秩序

本节吸收自 artience, “Harmony of color schemes,” *Color theory that can be used at work*, Basics #06（页面更新：2023-10-06，https://www.artiencegroup.com/en/column/chromatics/basic/006.html）。它是通用配色方法，不是 ArcheBase VI 原始条文；品牌 token、官方比例和色彩语义仍以 `archebase-vi-guide` 为准。

### 先选相似或对比

- **相似和谐**：使用同色相、邻近色相、相近明度/彩度，或共享某种色彩成分，建立统一、稳定、连续的关系。
- **对比和谐**：使用明确的明度、色相或彩度差异，建立焦点、方向、分组或动态；差异应足够清楚，避免落入“差一点但说不清”的暧昧区。

对 ArcheBase，默认先选相似和谐：用 `AB_CHARCOAL`、白/浅色应用表面和蓝色层级建立结构；需要表达信号、流向、转折或关键证据时，再用受控对比。对比不是增加更多颜色，而是让少量已批准 token 在明度、面积、位置、密度或角色上产生明确差异。

### 让色彩关系有秩序

色彩组合更容易稳定，不是因为存在跨文化的“绝对美”，而是因为色相、明度、彩度和排列形成可辨认的秩序。执行时：

1. 先固定一个变量：同色相、同 tone、同明度轴或同一中性色阶。
2. 再只改变一个主要变量：色相用于区分类别/方向，明度用于层级，彩度用于强调，面积用于权重。
3. 检查颜色排列、阅读顺序和面积分布是否支持同一信息关系。
4. 对近似但不明确的颜色关系继续拉开差异，或退回相似和谐；不要保留“看起来像错误”的中间状态。

### 多色方案的两种工作模式

- **Tone-led**：以相同或相近色相为主，通过明度/彩度/色调差异建立层级和节奏；适合稳定、工程、连续阅读和系列系统。
- **Hue-led**：使用多个色相制造活力和方向，但让 tone 或明度保持一定秩序；适合需要区分多类状态、过程阶段或明显转折的场景。

在 ArcheBase strict 模式中，优先使用 Tone-led；Hue-led 只能在已有 token 能清楚承载关系时使用，不能为了“丰富”而扩展色相。`guided`/`creative` 若使用活动扩展色，必须按模式记录为非官方 token，并回到 `archebase-vi-guide` 过对应门禁。

### 适用性与限制

色彩和谐是选择和组织关系的起点，不是发布标准，也不保证所有受众有相同审美评价。地域、经验、行业和文化会影响偏好；因此最终判断仍需结合受众、媒介、内容目标、实际尺寸、灰度、色觉模拟、对比度和可读性验证。

## 可访问性与测试

颜色不能单独表达状态、类别、方向或风险；补充文字、标签、图标、形状、位置、纹理或线型。逐一检查正文、标题、细线、图标和状态元素的对比度。

- 灰度：信息层级和阅读路径仍清楚。
- 色觉模拟：颜色合并时仍可理解。
- 实际尺寸：手机缩略图、网页字号、投影、展板距离和印刷尺寸分别检查。
- 背景：白底、深底、图像底和复杂纹理底分别检查。
- 非色彩复述：去掉颜色后，用户仍能理解结构和状态。
