# 图形生产与印前检查

## 栅格与矢量

- Logo、图标、线框、文字和几何图形保持矢量；照片、扫描和连续色调纹理使用栅格。
- 检查最终放置尺寸下的有效 PPI，而非文件标称值。传统网点印刷可用 `所需 PPI ≈ 2 × LPI` 作起点；大幅面按观看距离和供应商要求。
- “网页 72 PPI”不是现代数字交付规则；按最终像素、设备倍率、平台压缩和体积决定。
- 阴影、透明、模糊等可能触发栅格化；小字、细线和 Logo 不按照片分辨率栅格化。
- 保留可编辑母版，避免过早扁平化。

## 色彩管理

- 屏幕交付 RGB；印刷 CMYK 条件由印机、纸张、油墨和供应商 ICC 决定。
- 源图保留正确 ICC；未校准显示器不能作为品牌色批准依据。
- 软打样检查超色域、黑版、灰平衡和暗部；关键品牌色用目标承印物实体样批准。
- 专色名称必须完全一致；检查分色预览，避免透明/渐变生成意外色版。
- 小黑字通常单黑；大面积丰富黑、总墨量、叠印和反白细字必须由印厂确认，不自行套配方。

## 文件路由

- 保留带图层、链接和可编辑文字的原生母版。
- 矢量标志保留矢量母版；照片保留高位深、低损/无损工作母版。
- 印刷生产优先使用供应商指定 PDF/X：X-1a 为 CMYK/专色且透明扁平；X-3 可带 ICC RGB/Lab 但透明扁平；X-4 支持 ICC RGB/Lab 与实时透明。不要自行选择版本。
- 数字版按最终像素另存 RGB，不直接复用 CMYK 成品；检查平台重采样、透明、压缩、小字和细线。

## 印前预检

### 页面
- [ ] 成品尺寸、页数、方向、出血、安全区符合模板。
- [ ] 装订、折页、书脊、跨页、爬移已确认。
- [ ] 刀模、折线、烫印、UV 等位于独立命名层/专色版。

### 图像与图形
- [ ] 链接完整且为最终版；有效 PPI 达标。
- [ ] 无意外拉伸、低清放大和错误裁切。
- [ ] Logo、文字和细线保持矢量；线宽为明确值而非设备 hairline。
- [ ] 透明、阴影、叠印和混合模式在最终 PDF 一致。

### 字体
- [ ] 无缺失/替换/伪粗体/伪斜体。
- [ ] 授权允许嵌入、输出和供应商传递。
- [ ] PDF 字体嵌入或子集化；转曲只用于必要最终资产，保留未转曲母版。
- [ ] 中文标点、数字和字距在最终 PDF 复核。
- [ ] 渲染与打样字体已记录并通过**实际解析验证**：上游 VI 不随附字体文件，渲染/打样可使用另行取得许可的同设计字体（中文以 Noto Sans CJK SC 或思源黑体实现，拉丁用 Poppins）。渲染前必须确认实际解析到的 family（`fc-match '<family>'`；PDF 侧查 `/BaseFont` 嵌入表），确认结果与实际 family、字重、文件、授权一起记入 `visual-spec.md`。解析到替代字体（例如落到 PingFang SC / Helvetica）时交付状态记 `待确认`，不得声明已按 VI 字体渲染；缺少可验证字体时保留 live text 与可复现的字体配置。

### 颜色
- [ ] RGB/CMYK/灰度/专色符合路线；ICC 与目标条件一致。
- [ ] 专色名统一，无意外色版；分色预览无隐藏元素和错误套印。
- [ ] 小黑字、丰富黑、反白字和总墨量已确认。
- [ ] 超色域品牌色有实体打样或替代方案。

### 输出
- [ ] 输出预览检查页面框、分色、叠印和透明。
- [ ] 逐页打开成品，不只相信“导出成功”。
- [ ] 文件名、版本、日期、审批状态清楚；提供规格与预检报告。

## 打样与批准

先内容校样，再颜色/生产校样。颜色关键项目使用匹配目标条件的实体样，在标准光源比较。透明、叠印、反白细字、渐变和大面积品牌蓝重点检查。记录文件版本、样张类型、允许偏差、审批人和日期。可变数据先跑最长/最短文字、缺图、特殊字符、极值数字和分页边界。

## 素材记录

每项外部图片记录：`asset_id / 文件名 / 作者 / 来源URL / 下载日期 / 署名 / 修改记录 / 使用范围 / 审批状态`。

第三方素材在内部默认按已获授权处理，本 Skill 不维护许可台账；对外发布前由发布方确认授权；仍需按渠道核对可商用范围、肖像权、场地、艺术品、商标和生成式平台条款，并在向供应商打包字体和素材时确认可用性。

## 本 Skill 默认值（供应商/渠道可覆盖）

以下数值是**本 Skill 的工作默认值，不是上游 VI 规定**；供应商/渠道规范优先，冲突时以供应商为准。供应商未回复前先按默认值出稿，不因等待规格而停工。

- 出血 3 mm（大幅面/特殊工艺按供应商）；安全区 ≥ 10 mm（小尺寸渠道可降到 5 mm，但必须在 `visual-spec.md` 写明实际值；供应商规格待确认时先按此默认）。此为印刷/数字版心安全区，不是 Logo 安全区。
- 最细线宽 ≥ 0.25 mm（本 Skill 默认值；供应商可覆盖）。0.25 mm 是矢量声明值的下限，没有任何余量：刚好取 0.25 mm 时必须在 300 dpi 输出上验证至少 3 个满覆盖像素，否则加粗或改线型。
- 正文最小字号 ≥ 6 pt，反白字 ≥ 7 pt；**白底**小字不用浅蓝/青色（深底反白可用青色，但必须实测对比度 ≥ 4.5:1，见 [accessibility.md](accessibility.md)）。
- 交付文件不带裁切标记；裁切/折线/出血层单独命名；PDF/X 版本由供应商指定，不自行选择。
- 图片有效分辨率按放置尺寸计算（传统网版起点 ≈ 2×LPI），不用“网页 72 PPI”。

## 必须向供应商确认

上述默认值是供应商回复前的起点；供应商规格到达后以其为准并更新 `visual-spec.md`。

出血、安全区、最小字号/线宽/反白元素、LPI/FM/PPI、CMYK ICC、总墨量、丰富黑、PDF/X、透明、陷印、专色、纸张与工艺、大幅面距离、数字平台像素/压缩、无障碍标准。不存在“300 DPI + CMYK”万能规格。
