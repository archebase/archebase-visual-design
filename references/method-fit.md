# 设计方法反刍与 VI 适配

## 目的与证据边界

本文件不是新的品牌规范，也不是任何书籍的复述。它把当前 `archebase-visual-design` 已明确引用的方法，按 ArcheBase VI Guide 的调性、证据边界和模式规则重新筛选为：核心方法、条件方法和排除项。

品牌事实、官方 Logo、色值、字体证据、渠道硬规则和发布 verdict 仍由 `archebase-vi-guide` 负责。本文件只回答“什么设计方法适合用、在什么条件下用、为什么”。

以下盘点基于当前技能中显式标注的来源与现有方法文件；内部来源台账位于 `archebase-design-workspace`，本文件不替代其授权或逐来源记录。

## 配色理论来源补充

已吸收 artience, “Harmony of color schemes,” *Color theory that can be used at work*, Basics #06（页面更新：2023-10-06，https://www.artiencegroup.com/en/column/chromatics/basic/006.html）。吸收范围：相似/对比和谐、用色相—明度—彩度及排列建立秩序、Tone-led 与 Hue-led 两种组织方式、避免暧昧的近似差异。该来源只作为通用设计方法，不是 VI 原始条文；它不改变 ArcheBase 五色 token、Guide p.28 比例或 `strict/guided/creative/off` 边界。

## 适合 VI 调性的核心方法

以下方法在 `strict`、`guided` 和 `creative` 中都可用；模式只改变允许的表达幅度，不改变事实和可读性责任。

### 1. 语义先于风格

先写清楚受众、一个主判断、证据和行动，再选择形式。禁止从“科技感、未来感、高级感”开始。ArcheBase 的形式必须帮助观众理解物理现实、数据组织、验证关系或智能行动。

### 2. 证据决定图形类型

- 真实设备、环境和材料：证明物理现实、尺度和现场关系。
- 图示：解释输入、输出、连接、层级和状态变化。
- 数据图：表达可追溯的比较、分布或趋势。
- 技术插图：解释不可直接观察的内部结构，但不得被误读为真实产品截面。
- 概念图或生成图：只表达方向或隐喻，必须避免伪造现场、设备、客户和实验结果。

### 3. 结构先于装饰

先用黑白、单色或低装饰原型建立阅读顺序，再加入品牌颜色和图像。主轴、网格、留白、尺度和密度必须在去色后仍成立。颜色用于强化已存在的关系，不替代关系。

### 4. 稳定系统内的受控变化

系列物料固定主网格、字体角色、颜色角色、来源区和核心轴线；变化图像跨度、数据密度、节点分布、流向、裁切和局部尺度。结果应像“同一系统的不同状态”，而不是每页重新发明风格。

### 5. 物理性与抽象性的连续关系

抽象图形必须能回到可说明的物理对象、数据关系或过程阶段。优先使用“物理场 → 采集/组织 → 可验证结构 → 智能行动”的关系链；不要用随机节点、粒子、光晕或电路纹理制造没有证据的技术暗示。

### 6. 真实媒介中的判断

版面、字号、图像、线宽、颜色和对比度必须在实际尺寸、观看距离、设备、裁切和压缩条件下检查。屏幕缩略图、手机卡片、报告页面、展板和印刷品不是同一个版面，只是同一设计系统的不同状态。

## 条件适用的方法

| 方法 | 允许条件 | 不能越过的边界 |
|---|---|---|
| 破格、越栏、解构 | 有明确语义：断裂、汇聚、异常、转折、流动或系列节奏 | 必须保留锚点；不能遮挡来源、数据、正文或 CTA |
| 拼贴、遮挡、图底实验 | 能表达尺度、层叠、物理场或复杂关系 | 不能让实验形式先于主判断；不能制造伪证据 |
| 高密度信息场 | 内容确实需要展示覆盖、网络、样本或复杂度 | 必须分层、序列化并在缩略图和实际尺寸检查；不能用噪声冒充复杂度 |
| 活动扩展色 | 仅 `guided`/`creative`，且明确标为非官方 token | 不改 Logo；不称为品牌色；记录用途、理由和 owner；最终由 `vi-guide` 过对应门禁 |
| 含蓄、多义、象征性图像 | 适合 campaign/editorial，且核心判断仍一眼可见 | 不得用于掩盖未确认事实；不得把隐喻当成产品能力或现场证据 |
| 受控偶然、生成式纹理 | 作为次级表面或节奏，不承担事实和结构 | 范围、种子/参数、裁切和人工校正可复核；不能生成 Logo、文字或客户/设备“证据” |

`strict` 模式默认不使用上述条件方法，除非它们能被明确记录为内容必要且不违反 Guide 证据；`guided`/`creative` 使用时记录偏离理由。

## 应排除的方法

- 泛化的蓝紫赛博渐变、发光大脑、随机电路板、二进制雨、无来源仪表盘。
- 只靠多颜色、渐变、阴影、玻璃拟态或粒子制造“高级感”。
- 为了视觉冲击牺牲正文、来源、单位、图例、CTA 或替代文本。
- 直接移植历史风格或案例外观，并声称因此符合 ArcheBase VI。
- 用生成图暗示不存在的设备、客户、实验、部署现场、指标或架构。
- 用未经验证的色彩心理学、文化寓意或固定字体排名替代真实媒介测试。

## 设计方向选择算法

1. **定义判断**：写出唯一主判断、受众、行动和媒介。
2. **分级证据**：区分事实、可视化推断、概念提案和纯装饰；事实与可验证证据优先。
3. **选择表示**：按图像职能选择摄影、图示、数据图、技术插图或概念图。
4. **选择结构**：连续阅读用单栏；并列关系用分栏；高复杂度才用模块；海报/主视觉才使用层级网格或局部破格。
5. **选择表达幅度**：先按 VI mode 选择稳定程度；不要先选风格再找理由。
6. **建立系统**：固定字体角色、颜色角色、主轴、来源区和基本单元；只开放少量有语义的变化变量。
7. **做负面测试**：去色、缩略图、最长文案、缺图、极端裁切、色觉模拟和实际尺寸检查。
8. **记录偏离**：任何扩展色、破格、生成纹理、隐喻或非标准构图都写明打破的规则、沟通收益、风险和 owner。
9. **回到 VI 门禁**：品牌事实、资产、权利、Claims/Rights、Export/QA 和最终发布 verdict 回到 `archebase-vi-guide`。

## 反刍结论与优先级

### 已基本吸收

- 语义—句法—语用的设计纪律。
- 网格选择、系列化和受控破格。
- 图像职能、图表真实性、图注与来源。
- 情境化可读性、真实尺寸测试和行为/主观指标区分。
- 语义结构、替代文本和颜色非唯一编码。
- 矢量/栅格、色彩管理、印前与供应商边界。

### 仍需补强

1. **配色理论**：Artience 的色彩和谐方法已吸收；下一步是将其转为 ArcheBase 五色 token 的案例矩阵。若取得《配色设计原理》授权 PDF，再补充该书特有的章节、案例和修正方法；不能用二手摘要代替。
2. **跨渠道系统**：把“同一系统的不同状态”落成海报、社媒、报告、网页和活动屏幕之间的可复用变量与不可变变量。
3. **序列叙事**：把轮播、长图、报告和视频场景的节奏、信息递进和跨页记忆点进一步模板化。
4. **图形编码审查**：为节点、线、面积、位置、方向、密度、透明度和颜色建立“一个视觉变量对应一个信息变量”的检查表。
5. **评议指标**：在现有定性评议之外，增加识别正确率、信息检索时间、理解率或任务完成率等适合项目的行为指标。

优先顺序：先将 Artience 的色彩和谐原则转成 ArcheBase 五色 token 的案例矩阵，再补跨渠道系统、序列叙事和图形编码；取得《配色设计原理》授权 PDF 后再吸收其特有内容。不要继续增加装饰风格或更多抽象母题。
